Packages I design, build, and maintain, published to PyPI and crates.io. Each one started as something I needed for my own work and grew into a tool I keep sharpening.

kalbee — Python · PyPI

A clean, modular toolkit for Kalman filtering and state estimation, bringing ten filter families together under one consistent API.

  • Breadth: Kalman, Extended, Unscented, Particle, Ensemble, Information, Adaptive, and Square-Root filters, plus an RTS smoother for post-processing.
  • Tracking: Multi-object tracking with Hungarian association, track lifecycle management, and ready-made constant-velocity, constant-acceleration, and coordinated-turn motion models.
  • Numerical rigor: Joseph-form updates and Cholesky stabilization, with RMSE, NEES, NIS, and log-likelihood diagnostics built in.
Python State Estimation Sensor Fusion Tracking

colonyx — Rust + Python · crates.io · PyPI

Rust-backed swarm intelligence optimization for Python — a Pythonic interface over a compiled core, so the ergonomics never cost you the runtime.

  • Eleven algorithms: Ant Colony, Particle Swarm, Artificial Bee Colony, Grey Wolf, Firefly, Simulated Annealing, Cuckoo Search, Bat, Glowworm, Bacterial Foraging, and Differential Evolution.
  • One entry point: A unified AutoColony API covers both continuous function optimization and discrete problems such as the Traveling Salesman.
  • Rust core, Python surface: Compiled via PyO3 and shipped to both registries, so it is equally at home in a notebook or a Rust binary.
Rust PyO3 Python Optimization

enigmar — Rust · crates.io

A high-performance Enigma machine simulator covering the M3 and M4 models, with Python bindings for anyone who would rather explore the cipher from a notebook.

  • Historical fidelity: Models the rotor, reflector, and plugboard mechanics of the M3 and M4 machines.
  • Two audiences: A Rust crate for speed, plus Python bindings for teaching, tinkering, and cryptanalysis experiments.
